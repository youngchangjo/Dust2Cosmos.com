# SEO·GEO 검토 — 우주먼지 3.0

2026-09-08 · 로컬 구현 검토 완료 · 배포·색인·노출 효과는 미검증

## 검색 가능한 본문과 언어

| 항목 | 기존 문제 | 반영한 내용 |
| --- | --- | --- |
| 제품 설명 | 기존 2.0 중심, 현재 확장 Pro와 다른 구매 설명 | 출시 예정 3.0, 기존 무료 범위, 단일 Pro, 확장 여정과 과학적 한계를 함께 설명 |
| iPad | 존재감 부족 | 큰 가로 목업, iPhone과의 비교 설명, 기기별 탐험 흐름, 별도 FAQ |
| 한국어 색인 | 같은 주소에서 클라이언트 언어 변경 | 완성된 영문 `/`와 한국어 `/ko/` HTML, 언어별 제목·설명·자기 canonical |
| 언어 관계 | 별도 한국어 주소 부재 | 양방향 `en`, `ko`, `x-default` hreflang 및 실제 언어 링크 |
| 검색 의도 | 기능 소개 위주 | 앱 정의, iPad 지원, 3.0 시점, 무료/Pro, 관측/모델, 오프라인, 선정 이력 질문에 직접 답변 |
| 내용 접근 | 동작 코드 의존 | JS 없이 네 탐험 설명·FAQ·메뉴·다운로드 링크 모두 유지 |
| 엔터티 연결 | 제한된 제품 맥락 | Organization → WebSite → SoftwareApplication → WebPage JSON-LD, 공식 App Store·개발자 연결 |
| 공유 미리보기 | 범용 SVG | 언어별 1200×630 JPEG, OG/Twitter 제목·설명·alt·크기 |
| 탐색과 크롤링 | 단일 랜딩 중심 | 네 공개 canonical 경로의 sitemap, 공개 콘텐츠 allow, 내부 문서/스크립트 경로 제외 |
| 이미지 | 화면 교체·크기 정보 관리 필요 | 설명형 alt, 고정 종횡비, WebP srcset, 첫 이미지는 eager/high priority, 나머지는 lazy |

Google의 [다국어 문서](https://developers.google.com/search/docs/specialty/international/localized-versions)에 맞춰 별도 URL과 서로를 가리키는 언어 대체 링크를 사용했습니다. 자동 언어 리다이렉트 없이 방문자가 언어를 선택할 수 있습니다.

## AI 검색에서 설명하기 쉬운 제품 정보

제품명 두 가지, 개발자, 지원 기기, 앱의 목적을 본문에 자연스럽게 연결했습니다. 버전·무료/Pro·과학 자료의 성격을 묻는 FAQ는 짧고 독립적으로 이해할 수 있게 작성했습니다. 천체 수나 수상 점수를 늘어놓거나 숨겨진 검색어를 추가하지 않았습니다.

정형 데이터는 보이는 내용과 맞춥니다. 미출시 3.0을 앱의 현재 `softwareVersion`으로 선언하지 않았고, 확인하지 않은 가격·평점·수상 `award`도 넣지 않았습니다. SoftwareApplication 엔터티는 앱을 설명하기 위한 것으로, 가격·리뷰 요구 사항을 충족하는 앱 리치 결과를 약속하지 않습니다. 상업용 랜딩의 FAQ에는 리치 결과를 기대하는 FAQPage 마크업을 추가하지 않았습니다.

[Google의 AI 검색 안내](https://developers.google.com/search/docs/appearance/ai-features)는 읽을 수 있는 본문, 일반 SEO와 검색 자격을 강조하며 특별한 AI 파일이나 전용 스키마를 요구하지 않습니다. `llms.txt`는 사실 확인에 편리한 선택형 제품 요약으로만 추가했습니다. AI 인용, 검색 순위 또는 크롤러 사용을 보장하는 장치로 취급하지 않습니다.

과거 Apple 편집 선정의 제목과 지역을 본문에 넣고 공식 컬렉션으로 연결했습니다. 후속 세션 조사에서 당시 작성된 2026년 7월 4일 보고서를 복구해 ‘2026년 7월’을 반영했습니다. 미국 Best New Apps and Updates와 캐나다 Hot This Week를 구분합니다. 확인일을 최초 선정일이나 현재·3.0 선정으로 확대하지 않았습니다. 근거와 컬렉션 변경 한계는 [출처 기록](landing-3.0-sources.md)에 있습니다.

## 성능과 시각 품질의 균형

- 정적 HTML과 로컬 시스템 폰트가 먼저 표시됩니다. 앱 프레임워크·CDN·분석 추적기는 없습니다.
- 생성된 대표 이미지의 각 WebP 변형은 250 KB 미만입니다. 이미지 크기를 미리 확보해 레이아웃 이동을 방지합니다.
- 실제 지구 자전은 별도의 점진적 WebGL 향상입니다. 텍스처는 데스크톱 약 3.77 MB, 작은 화면 약 1.20 MB 추가이며, 메인 표면과 구름 품질을 우선한 선택입니다. 이는 정적 이미지 예산과 구별합니다.
- 자전은 30fps를 목표로 제한하며 화면 밖/숨겨진 탭/수동 정지에서는 지속 렌더링을 멈춥니다. 동작 줄이기로 처음 방문하면 3D 지도 다운로드를 생략합니다.
- GPU 미지원·컨텍스트 상실 시 생성 포스터가 표시되고 본문/CTA는 계속 사용할 수 있습니다.

브라우저 기록의 LCP·CLS와 GPU 프레임 수는 로컬·비제한 환경의 표본입니다. 실제 모바일 네트워크, 전체 방문자 Core Web Vitals 또는 검색 순위 점수로 해석하지 않습니다.

## 남겨둔 공개 이후 확인 사항

현재 미리보기는 `127.0.0.1` 전용이며 응답 헤더로 noindex입니다. 소스의 공개 페이지 메타데이터는 향후 게시용 canonical을 갖추지만 이번 작업에서는 게시하지 않았습니다.

사용자가 나중에 게시를 결정하면 실제 호스트의 canonical/리다이렉트/robots/noindex 해제 여부, 네 페이지 응답, 공유 카드, Search Console 수집·색인 상태와 실제 트래픽 성능을 확인해야 합니다. 외부 검색 콘솔 연결이나 데이터가 없으므로 색인 수, 노출 수, 검색 순위, AI 답변 인용률은 측정하지 않았습니다. 검색 엔진 제출도 수행하지 않았습니다.
