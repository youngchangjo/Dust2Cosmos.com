## Web Earth provenance and image generation

[Solar System Scope](https://www.solarsystemscope.com/textures/) publishes the texture collection under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The already bundled day, cloud, night, specular and normal maps are resized and encoded for the website. `assets/earth/credits.json` records original hashes, derivative dimensions, credits and modifications. Lighting, cloud shading, atmosphere and accelerated rotation are authored promotional models. The hero does not show current weather or the native renderer.

The four generated promotional assets use the prompts in `landing-3.0-image-prompts.json`; optimized files and source hashes are in `assets/media/manifest.json`. The UI section and virtual-flight illustration carry visible concept captions. Full generated images were inspected before integration. The built-in generation tool did not expose an exact model selector.
