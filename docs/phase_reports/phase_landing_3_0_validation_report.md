## 결과와 범위

기존 `DustToCosmos-site`를 출시 예정 3.0 중심으로 개편했습니다. 모든 영역은 시스템 설정과 무관하게 다크 테마를 유지합니다. 메인에는 실제 WebGL 2 지구 자전, iPad·iPhone 영역에는 교체 가능한 생성 UI 목업을 적용했습니다. 한국어·영어 본문, 단일 Pro와 기존 무료 범위, 확장 여정, 과학적 출처, 과거 미국·캐나다 App Store 편집 선정 이력을 반영했습니다.

기준 커밋은 `3c0417d`. 작업 대상은 웹사이트 저장소이며 네이티브 앱 저장소는 수정하지 않았습니다. 원래 있던 `.DS_Store` 변경과 `docs/superpowers/plans/2026-05-08-website-readiness.md`는 이번 커밋 대상에서 제외합니다. 배포·원격 푸시·App Store 변경은 수행하지 않았습니다.

## 성능·접근성 해석의 한계

지구의 표면·구름은 큰 화면에서 4K, 작은 화면에서 2K를 사용합니다. 추가 텍스처 전송량은 각각 3,768,266바이트와 1,196,356바이트입니다. 첫 포스터는 별도 WebP이고, 초기 동작 줄이기에서는 이 텍스처들을 요청하지 않는 것을 검증했습니다. 모든 화면 밖 중지는 실제 스크롤로, 숨겨진 문서 중지는 `visibilitychange`와 `document.hidden` 주입으로 검사했습니다.

최초 headless Chromium 표본은 SwiftShader와 캡처 부하를 포함했습니다. 이번 headful Chromium의 비제한 loopback LCP 표본은 EN 276ms·KO 144ms, CLS는 약 0.000167·0.000132입니다. 캐시·로컬 연결·실제 Mac GPU 조건에서 얻은 값이며 모바일 네트워크나 실제 사용자 Core Web Vitals를 입증하지 않습니다. 별도 데스크톱 GPU 표본 역시 물리 iPhone/iPad 속도나 전력 소모를 입증하지 않습니다. 실제 배포 환경의 네트워크·캐시·장기 방문자 지표는 공개 이후 별도 측정 대상입니다.

axe가 수동 확인으로 남긴 `aria-prohibited-attr`·`color-contrast` 항목을 원시 결과에 남겼습니다. 키보드와 시각 검토를 수행했지만 전체 VoiceOver·동적 배경 모든 프레임에 대한 WCAG 인증을 주장하지 않습니다. WebKit은 로컬 엔진이며 실제 iPad Safari 기기 검사를 대신하지 않습니다.

## 문구와 이미지

3.0의 9월 22일은 목표일로 안내합니다. App Store 링크는 현재 출시된 앱으로 연결합니다. UI 목업과 가상 항해는 생성 콘셉트로 표기합니다. 지구 연출에는 지도 출처·라이선스·변환 사실을 표시하며 현재 구름 관측이나 실제 앱 캡처로 소개하지 않습니다.

Apple 선정은 역사적 편집 이력으로 표시합니다. 후속 조사에서 해당 Codex 세션의 원래 2026년 7월 4일 보고서를 찾아 2026년 7월을 확인했습니다. 미국은 Best New Apps and Updates, 캐나다는 Hot This Week였고 두 지역 모두 iPhone·iPad에 해당합니다. 7월 4일은 확인일이며 최초 선정일을 확정하지 않습니다. 제품·Apple·과학 자료 출처와 원본 보고서는 [근거 문서](../landing-3.0-sources.md), 검색 설계는 [SEO·GEO 검토](../SEO_GEO_REVIEW.md), 목업 교체 절차와 전체 프롬프트는 [README](../../README.md)에 있습니다.

검토 화면은 [시각 리포트](phase_landing_3_0_visual_report.html), 실제 움직이는 페이지는 http://127.0.0.1:8893/ko/ 에서 확인합니다. 최종 시각 취향과 실제 화면 교체는 사용자의 후속 검토를 기다립니다.

## 선정 월 후속 검증

사용자가 이전 Codex 확인 기록을 요청해 원래 7월 4일 조사 산출물을 복구했습니다. 한·영 선정 영역과 FAQ, `llms.txt`와 근거 문서를 수정하고 원본 보고서를 동일한 바이트로 보존했습니다. 첫 선정 시작일을 추정해 넣지는 않았습니다.

기본 개편의 브라우저 38개·3D 9개 결과는 `e3567e9`에서 확인한 범위입니다. 이번 문구·선정 영역 변경은 정적 234개 재검사와 EN/KO 각각 320·390·1440px의 6개 화면 검사로 확인했습니다. 날짜, 국가별 제목과 링크, FAQ의 확인일 구분, 다크 고정, 가로 넘침 및 선정 영역 axe 검사 모두 통과했습니다. [후속 결과](artifacts/landing_3_0/featuring-july-checks.json)와 한·영 캡처를 보존하고 전체 페이지 이미지도 갱신했습니다. 렌더러를 수정하거나 앱을 게시하지 않았습니다.

## 첫 진입과 시각 피드백 반영

메인 제목 위의 출시 보조 문구를 제거했습니다. 본문은 16–17px, 주석·캡션·하단 정보는 14px를 기준으로 조정했습니다. Best New Apps and Updates를 37–76px 제목으로 강조하고 2026년 7월 및 미국·캐나다의 서로 다른 편집 제목을 그대로 유지했습니다.

별도의 생성 지구와 WebGL 지구 사이에서 구도·빛이 바뀌던 첫 진입 문제를 고쳤습니다. 실제 셰이더를 시간 0으로 캡처한 포스터를 쓰고, 포스터의 CSS 좌표와 크기를 3D 구면도 읽습니다. 390·1180·1440px에서 지도 로딩을 보류한 뒤 첫 프레임을 비교했습니다. 평균 RGB 차이는 255 중 1.26–2.56, 24 이상 차이가 나는 픽셀은 0.30% 미만이었습니다. 압축·리샘플 차이는 남지만 지구의 위치·크기·대륙·광원은 유지됩니다. 포스터는 1024px 243 KB / 2048px 761 KB이며 고해상도 첫 장면 품질을 위해 큰 변형에만 800 KB 예산을 둡니다.

화면에 CSS 테두리를 씌우던 구성을 실제 금속 프레임·유리·카메라가 표현된 생성 iPad·iPhone 목업으로 교체했습니다. 홈페이지는 기기 포함 이미지 한 장을 사용하고 생성 UI 안내를 유지합니다. 탐험 탭의 장식 SVG와 선으로 그린 지구 기호를 제거했으며 출처 영역에는 생성된 달·지구 이미지를 배치하고 콘셉트임을 표시했습니다. 생성·편집은 내장 image_gen 도구를 사용했습니다. 중간 투명 배경 요청 결과에 체크무늬가 그려져 있었으므로 그것은 채택하지 않고 최종 검정 배경 합성본을 사용했습니다.

이번 변경 상태에서 정적 **248/248**, Chromium·WebKit **38/38**, 실제 Mac GPU 지구 동작 **9/9**, 첫 진입·가독성·목업 배치 **11/11**을 확인했습니다. EN/KO 320·390·768·1440px에서 텍스트 최소 14px, 메인 제목 첫 요소, 제목 위 문구 제거, 헤더·본문 무겹침, 가로 넘침 없음, 지역·날짜 유지와 실제 이미지 로딩을 검사했습니다. 자동 접근성 알려진 위반은 0입니다.

첫 진입 검사는 애니메이션 시간만 0으로 고정한 전후 비교이며 실제 자전·정지·동작 줄이기·화면 밖 중지는 별도 9개 검사로 다시 확인했습니다. 반응형 srcset의 naturalWidth는 표시 밀도가 반영된 값이므로 초기 QA의 고정 600px 가정을 제거하고 실제 소스와 디코딩 성공을 확인합니다. 전체 이미지 QA는 새 달 이미지 영역도 실제로 스크롤하고 유한 대기를 사용하도록 보완했습니다.
